Kontrol akses yang rusak akibat miskonfigurasi platform (Lab URL-based access control can be circumvented)
	Aplikasi mungkin membatasi perang user dengan membatasi akses ke url dan http method. contoh: DENY:POST /admin/deleteUser, manager
	yang artinya menolak akses melalui POST method di url /admin/deleteUser untuk user yang ada di grup manager.
	ini bisa mengarah ke akses kontrol bypass.
	
	beberapa framework mendukung header HTTP non standar untuk mengganti url pada permintaan asli seperti,
		X-Original-URL dan X-Rewrite-URL, jika aplikasi membatasi akses url, tapi menginjinkan url ditimpa melalu request header
		maka bisa dibypass dengan permintaan berikut :  POST / HTTP/1.1
								X-Original-URL: /admin/deleteUser
								...
