Apa itu DOM XSS?

DOM-based Cross-Site Scripting (XSS) adalah jenis kerentanan keamanan yang terjadi ketika skrip berbahaya dieksekusi di sisi klien (browser) akibat manipulasi Document Object Model (DOM). Dalam konteks ini, 
data yang tidak terfilter dari URL (seperti location.search) digunakan secara langsung dalam fungsi JavaScript, seperti document.write, yang dapat menyebabkan eksekusi skrip berbahaya.
Konteks Kerentanan DOM XSS

Kerentanan ini terjadi ketika aplikasi web menggunakan document.write untuk menampilkan data dari location.search. Jika pengguna dapat mengontrol parameter dalam URL, 
mereka dapat menyisipkan skrip berbahaya yang akan dieksekusi saat halaman dimuat.
Contoh Kode Rentan dengan Skrip Eksternal

Berikut adalah contoh aplikasi web sederhana yang memiliki kerentanan DOM XSS dan menggunakan JavaScript eksternal:

index.html

html

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Pencarian</title>
    <script src="script.js" defer></script>
</head>
<body>
    <h1>Selamat datang di aplikasi pencarian!</h1>
</body>
</html>

script.js

javascript

// Mengambil query dari URL
const query = location.search;

// Menulis query ke halaman menggunakan document.write
document.write(`<h2>Hasil Pencarian untuk: ${query}</h2>`);

Dalam contoh di atas, jika pengguna mengunjungi URL seperti index.html?query=<script>alert('XSS');</script>, maka skrip tersebut akan dieksekusi, menampilkan alert.
Cara Mengamankan dari DOM XSS

Untuk mengamankan aplikasi Anda dari DOM XSS, Anda dapat melakukan langkah-langkah berikut:

    Sanitasi Input Pengguna
        Pastikan untuk memvalidasi dan menyaring semua input pengguna sebelum menggunakannya.

    Encoding Output
        Gunakan fungsi untuk mengencode karakter khusus sebelum menyisipkannya ke dalam DOM. Anda dapat membuat fungsi sederhana untuk melakukan ini.

    Perbaikan Kode:

    script.js

javascript

function escapeHtml(unsafe) {
    return unsafe
        .replace(/&/g, "&amp;")
        .replace(/</g, "&lt;")
        .replace(/>/g, "&gt;")
        .replace(/"/g, "&quot;")
        .replace(/'/g, "&#039;");
}

// Mengambil query dari URL
const query = location.search;

// Mengencode query sebelum menulis ke halaman
document.write(`<h2>Hasil Pencarian untuk: ${escapeHtml(query)}</h2>`);

Dalam perbaikan di atas, fungsi escapeHtml digunakan untuk mengencode karakter khusus sebelum menyisipkannya ke dalam halaman. Ini mencegah eksekusi skrip berbahaya.

Hindari Penggunaan document.write

    Sebaiknya hindari penggunaan document.write untuk menambahkan konten ke halaman. Sebagai gantinya, gunakan metode yang lebih aman seperti textContent atau innerHTML dengan encoding yang tepat.

Contoh Alternatif:

javascript

    const resultElement = document.createElement('h2');
    resultElement.textContent = `Hasil Pencarian untuk: ${escapeHtml(query)}`;
    document.body.appendChild(resultElement);

Kesimpulan

DOM XSS adalah kerentanan serius yang dapat dieksploitasi oleh penyerang untuk menjalankan skrip berbahaya di browser pengguna. Dengan menerapkan sanitasi input, encoding output, 
dan menghindari penggunaan metode yang tidak aman seperti document.write, Anda dapat melindungi aplikasi web Anda dari serangan XSS, bahkan saat menggunakan skrip eksternal.
